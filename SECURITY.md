# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.x     | ✅         |

## Reporting a Vulnerability

If you discover a security vulnerability, please do **not** open a public issue.

Report it privately via one of these channels:

- **Email**: [hrudushibu.tech@gmail.com](mailto:hrudushibu.tech@gmail.com)
- **GitHub Security Advisory**: [Open a private advisory](https://github.com/hrudushibu/agent-safe/security/advisories/new)

Please include:
- A clear description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You can expect a response within **48 hours** and a resolution or status update within **7 days**.

We appreciate responsible disclosure and will credit reporters in the release notes.
